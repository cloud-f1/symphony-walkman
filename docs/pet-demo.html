An app of its own

The terminal pane can only draw text cells inside itself. A pet on the desktop needs its own transparent, always-on-top window, so it is a separate small app, not part of the plugin. clawd-on-desk is built the same way (an Electron app that listens to Claude Code through hooks).

What it listens to

Claude Code's session records in ~/.claude/sessions, plus a small state file the Walkman plugin writes (the owner agreed to that): the card, its light, the reason, the steps left.

What this page cannot show

The real pane never reports where it sits on screen, so the run out of the pane is an effect that starts at the screen's edge or the terminal window, not a measured path. Sizes and speeds are guesses to be tuned on a real Mac.
